# Posleslovie WP Transfer Kit V2

Ниже минимальные шаги, чтобы сайт заработал на WordPress с новой темой и корректными ассетами.

## Что использовать

- Тема: `posleslovie-theme-v2.zip`
- Пакет картинок и документов: `posleslovie-media-kit.zip`
- (Опционально) импорты:
  - `acf-json/group_posleslovie_home.json`
  - `forms/fluentforms-posleslovie-order.json`

## Шаги установки

1. Держи рабочую тему (Astra) активной.
2. Загрузить тему:
   - `Внешний вид -> Темы -> Добавить -> Загрузить тему`
   - выбери `posleslovie-theme-v2.zip`
   - сначала `Просмотреть`, потом `Активировать`
3. В `Настройки -> Чтение` назначь статическую главную страницу `Главная`.
4. Проверить, что главная открывается и стили/картинки появились.

## Что делать с картинками

Тема уже содержит fallback-ассеты внутри себя (`assets/media-kit`), поэтому картинки отображаются сразу.

Если хочешь хранить файлы в Media Library:

1. Распакуй `posleslovie-media-kit.zip` локально.
2. Загрузить файлы из:
   - `images/**`
   - `docs/legal/**`
3. При необходимости заменяй URL в контенте на URL из Media Library.

## Форма и ACF

Если нужно редактирование через поля и форма:

1. Импортируй ACF JSON в `Custom Fields -> Tools`.
2. Импортируй Fluent JSON в `Fluent Forms -> Tools`.
3. Вставь шорткод формы в нужный блок страницы вручную.
